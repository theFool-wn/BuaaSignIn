# BuaaSignIn

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-blue.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)  ![Made by Wang Nan](https://img.shields.io/badge/Made%20by-Wang%20Nan-brightgreen)

为了避免每次签到打卡都要排很长的队，所以制作该工具方便[签到](https://sign.wangnan.net)

1. 填写BUAA统一认证（SSO）账号、密码，点击「查询课程」
2. 选择要签到的课程，点击「签到」
3. 为保证合理使用，本工具**仅查询当日课程**，在**课程开始前10分钟至课程结束期间**允许打卡
4. 由于服务器资源限制，本工具仅限内部人员使用
5. 为保证账号安全，本工具使用RSA非对称加密，同时服务器不保存密码
6. 部分账号由于弱密码或频繁异地登陆，可能无法查询课程
7. 本项目仅用于个人学习和研究交流，请勿用于违反学校规定的用途
8. 使用本工具造成的一切后果由使用者自行承担

## ✅ Update 20260603
1. 使用方式变更为「账号 + 密码」
2. 密码使用RSA非对称加密保证安全，服务器不保存密码
